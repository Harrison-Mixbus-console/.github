# Harrison Mixbus — Professional Console Mixing with Analog Emulation

## About Harrison Mixbus

Harrison Mixbus provides a complete professional console mixing environment with analog emulation for audio engineers, mixers, and producers. Harrison Mixbus combines true analog summing, channel strip processing, and tape saturation. Harrison Mixbus supports built-in compression, equalization, and bus processing on every channel. Harrison Mixbus integrates Harrison’s film console design heritage from Grammy-winning studios. Harrison Mixbus enables mix engineers to achieve warm, console-style character entirely within digital workflow. Harrison Mixbus is trusted by mixing engineers, mastering engineers, film rerecording mixers, and home studio producers worldwide.
